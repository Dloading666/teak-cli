## English

### How to contribute

1. Create a feature branch from the current working branch.
2. Run `cargo check` and `cd src-ui && npm run build` before pushing.
3. Use Conventional Commits in English: `feat(area): ...`, `fix(area): ...`.
4. Describe *why*, not only *what*.

## 简体中文

本仓库基于 [Coffee CLI](https://github.com/edison7009/Coffee-CLI) 二次开发。

1. 从当前工作分支拉 feature 分支。
2. 推送前跑 `cargo check` 和 `cd src-ui && npm run build`。
3. Commit 用英文 Conventional Commits。
4. 代码按 AGPL-3.0-or-later 贡献，见 LICENSE / NOTICE。
5. 不要把 Coffee CLI 的名称或 Logo 装回本 fork 的对外界面。
