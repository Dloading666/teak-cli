<summary><b>🇨🇳 简体中文</b></summary>

- 终端支持自选字体:设置 → 终端,可从本机已安装的字体里挑选,带搜索和实时预览,选完即时生效。
- 修复:终端里的中文 / 日文 / 韩文在部分机器上字体不统一、显示偏丑的问题,现统一使用系统优质字体。

</details>

<details>
<summary><b>🇹🇼 繁體中文</b></summary>

- 終端支援自選字型:設定 → 終端,可從本機已安裝的字型裡挑選,附搜尋與即時預覽,選完即時生效。
- 修復:終端裡的中文 / 日文 / 韓文在部分機器上字型不一致、顯示偏醜的問題,現統一使用系統優質字型。

</details>

- Terminal font picker: choose any installed font in Settings → Terminal — searchable, with live preview, applied instantly.
- Fixed: Chinese / Japanese / Korean in the terminal fell back to an inconsistent or ugly font on some machines; now a consistent high-quality system face.

<details>
<summary><b>🇯🇵 日本語</b></summary>

- ターミナルのフォント選択に対応:設定 → ターミナル から、インストール済みのフォントを検索・リアルタイムプレビュー付きで選べ、即座に反映されます。
- 修正:ターミナルの中国語 / 日本語 / 韓国語が一部の環境で不揃い・見栄えの悪いフォントにフォールバックする問題を修正。統一された高品質なシステムフォントを使うようになりました。

</details>

<details>
<summary><b>🇰🇷 한국어</b></summary>

- 터미널 글꼴 선택 지원: 설정 → 터미널에서 설치된 글꼴을 검색·실시간 미리보기와 함께 선택할 수 있고 즉시 적용됩니다.
