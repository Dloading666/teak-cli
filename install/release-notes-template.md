- 「分类式」更贴近便签操作：点击分类标题即可直接改名，不再需要笔图标；长按（约 0.4 秒）即可拖动卡片排序；底部调整高度的手柄也改成与便签一致的短横条。右侧操作精简为「发送」「删除」两个图标，悬停时才显示（发送在上、删除在下）。
- 输入框的调整高度手柄，悬停时与拖动时效果一致：同样粗细、同样颜色，拖动时只是变长。
