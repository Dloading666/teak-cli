### Teak CLI v0.0.1

- **Teak CLI 的首个 GitHub Release。** 安装包从本仓库 GitHub Releases 分发；macOS DMG 与 Windows EXE 文件名为 `Teak.CLI_*`。应用内更新检查与下载都指向 `Dloading666/teak-cli`，不再走 coffeecli.com（那会装回上游 Coffee CLI）。
- **标题栏品牌居中，并与 Dock 图标一致。** 木纹斜体 T 加 prompt 标记；macOS 显示名通过 Info.plist 固定为 Teak CLI。
- **左侧会话栏在重启或应用内更新后会恢复。** 打开中的会话写入磁盘，并支持按项目拖拽排序。忙碌指示在回合结束后会停。
- **历史会话可直接关闭。** 右侧会话列表每条记录带关闭按钮，忙碌状态仍有独立指示。
- **应用内更新会实际安装。** Windows 走 NSIS 静默安装，macOS 替换 .app，Linux 处理 Deb / AppImage。
- **设置里的 GitHub 反馈指向本仓库 Issues。**

### Teak CLI v0.0.1

- **First GitHub Release of Teak CLI.** Installers ship from this repo's GitHub Releases. macOS DMG and Windows EXE files are named `Teak.CLI_*`. In-app update checks and downloads use `Dloading666/teak-cli` and never coffeecli.com (that package is upstream Coffee CLI).
- **The titlebar brand is centered and matches the Dock icon.** Italic wood-grain T plus a prompt mark; macOS display name is pinned to Teak CLI via Info.plist.
- **The left session rail survives restart and in-app update.** Open sessions are written to disk, with per-project drag-to-reorder. The busy indicator stops when the turn ends.
- **History sessions can be closed in place.** Each row in the session list has a close button, with a separate busy indicator.
- **In-app update actually installs.** Windows uses a silent NSIS install; macOS replaces the .app; Linux handles Deb / AppImage.
- **Settings GitHub feedback points at this repo's Issues.**

### Teak CLI v0.0.1
