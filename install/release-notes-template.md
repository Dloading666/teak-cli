- Recent folders: the folder icon on a tool card now opens a list of the project folders you've opened recently — click one to launch that card's tool there; "Open Folder" at the bottom still picks a new directory. Clicking the card body keeps the old flow.
- No more lag on large repos: with the Changes panel open on a big repository while an agent edits files hard, the UI is no longer dragged down by background Git queries — only one runs at a time, and .git internal churn is filtered so it refreshes only on branch switch / staging / commit (issue #40).
- Smoother on refocus: switching between tabs right after bringing Coffee CLI back to the foreground no longer stutters (issue #43).
