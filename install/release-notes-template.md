<summary><b>🇨🇳 简体中文</b></summary>

- 新增「便签式」任务形态(设置 → 任务 切换):一张大便签随手写,写完点 ▶ 整段发给 AI,不用再挤小输入框;左上红 / 黄 / 绿三点切优先级、自动排序,拖底边还能把便签拉大拉小。
- 首次打开会有一张「使用攻略」欢迎便签带你上手;列表空了也能从空状态的「查看使用攻略」再叫出来。

</details>

<summary><b>🇹🇼 繁體中文</b></summary>

- 新增「便籤式」任務形態(設定 → 任務 切換):大便籤隨手寫,寫完點 ▶ 整段發給 AI,不用再擠小輸入框;左上紅 / 黃 / 綠三點切優先級、自動排序,拖底邊還能把便籤拉大拉小。
- 首次打開有一張「使用攻略」歡迎便籤帶你上手;清單空了也能從空狀態再叫出來。

</details>

<details>
<summary><b>🇬🇧 English</b></summary>

- New Sticky-note task view (Settings → Tasks): a roomy note you write in freely, then hit ▶ to send the whole thing to your AI — no more cramped input box. Three dots set priority (red / amber / green) with auto-sort, and you can drag the bottom edge to resize the note.
- A welcome guide note greets first-time users; bring it back anytime from the empty board's "view the usage guide" button.

</details>

<details>
<summary><b>🇯🇵 日本語</b></summary>

- 新しい「付箋」表示を追加(設定 → タスク で切り替え):大きな付箋に自由に書いて、▶ を押せばまるごと AI に送れます。窮屈な入力欄とはお別れ。左上の3つの丸で優先度(赤 / 黄 / 緑)を切り替えると自動で並び替わり、下端をドラッグすればサイズも変えられます。
- 初回起動時は「使い方ガイド」の付箋がご案内。リストが空になっても、空の画面から再表示できます。

</details>
