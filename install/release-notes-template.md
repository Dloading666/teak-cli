### Teak CLI v3.4.8

- **以 Teak CLI 名义从本仓库 GitHub Releases 分发安装包。** macOS DMG 与 Windows EXE 文件名改为 `Teak.CLI_*`；应用内更新检查与下载都指向 `Dloading666/teak-cli`，不再走 coffeecli.com（那会装回上游 Coffee CLI）。
- **标题栏品牌居中，并与 Dock 图标一致。** 木纹斜体 T 加 prompt 标记；macOS 显示名通过 Info.plist 固定为 Teak CLI。
- **历史会话可直接关闭。** 右侧会话列表每条记录带关闭按钮，忙碌状态仍有独立指示。

### Teak CLI v3.4.8
