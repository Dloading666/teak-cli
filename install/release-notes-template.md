<summary><b>🇹🇼 繁體中文</b></summary>

- Gambit 左下角現在會顯示你正在傳送的工作區目錄名稱，隨 tab 切換即時更新——再也不怕把提示詞傳到錯誤的工作區。
- 便箋內容超出高度時現在可以平滑捲動：捲動或拖曳時出現一條細長的自動隱藏滑桿，不再有笨重的上下箭頭。
- 便箋底部的調整高度把手現在會亮起一條置中的短橫條，拖曳時顏色加深、長度變長。
