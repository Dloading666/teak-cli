<summary><b>🇨🇳 简体中文</b></summary>

### Teak CLI v0.0.2

- **左侧会话改名会写回 Grok 自己的会话元数据。** 栏上的名字和 `grok --resume <标题>` 保持一致；重启后自定义名称也不会丢。
- **Grok 回合结束后忙碌指示会停。** 不再被 OSC 里残留的 spinner 帧卡住。
- **会话名称优先用真实标题。** 不再被泛化的 “Grok Session” 一类占位名盖掉。

</details>

<summary><b>🇬🇧 English</b></summary>

### Teak CLI v0.0.2

- **Renaming a left-rail session writes back into Grok's own metadata.** The label stays in sync with `grok --resume <title>` and survives restart.
- **The busy indicator stops when a Grok turn ends.** A leftover OSC spinner frame no longer keeps the rail spinning.
- **Session names prefer the real title.** Generic placeholders like “Grok Session” no longer win.
