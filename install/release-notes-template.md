### Teak CLI v0.0.6

- **Grok 会话可以组成固定团队协作。** 一名负责人加最多三名执行者，只在绑定的 Grok 会话之间交换任务和报告，其他会话不受影响。
- **设置里可开关协作，并提供像素办公室快照。** 办公室只展示已提交、可核对的状态，不会把动画当成完成。
- **macOS DMG 内的 .app 会验签名。** 打包时关掉 hardened runtime，并检查 Sealed Resources，避免点图标没反应。

<summary><b>🇬🇧 English</b></summary>

### Teak CLI v0.0.6

- **Grok sessions can form a fixed collaboration team.** One leader plus up to three workers exchange tasks and reports only among bound Grok sessions; other sessions stay unchanged.
- **Settings can turn collaboration on, with a pixel-office snapshot.** The office shows verified submitted state and does not treat animation as completion.
- **The macOS DMG now verifies the embedded .app.** Hardened runtime stays off and Sealed Resources are required, so Gatekeeper does not silently reject launch.

### Teak CLI v0.0.6

- **Grok 工作階段可以組成固定團隊協作。** 一名負責人加最多三名執行者，只在綁定的 Grok 工作階段之間交換任務和報告，其他工作階段不受影響。
- **設定裡可開關協作，並提供像素辦公室快照。** 辦公室只展示已提交、可核對的狀態，不會把動畫當成完成。

### Teak CLI v0.0.6

- **Grok セッションで固定チームを組めます。** リーダー 1 人とワーカー最大 3 人。バインドした Grok セッション同士だけがタスクと報告をやり取りし、他のセッションはそのままです。

<summary><b>🇰🇷 한국어</b></summary>

### Teak CLI v0.0.6

- **Grok 세션으로 고정 팀을 만들 수 있습니다.** 리더 1명과 워커 최대 3명. 바인딩된 Grok 세션끼리만 작업과 보고를 주고받으며 다른 세션은 그대로입니다.
- **설정에서 협업을 켜고 픽셀 오피스 스냅샷을 볼 수 있습니다.** 제출되어 검증된 상태만 보여 주며, 애니메이션을 완료로 보지 않습니다.
- **macOS DMG 안의 .app을 검증합니다.** hardened runtime은 끈 채로 Sealed Resources를 요구해, 아이콘을 눌러도 안 켜지는 문제를 막습니다.
