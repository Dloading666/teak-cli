- **左侧文件树折叠会带动画。** 目录不再瞬间消失，高度和透明度一起收起，系统开了减少动态效果时会关掉动画。

### Teak CLI v0.0.7

- **The file tree now animates collapse.** Folders ease height and opacity instead of vanishing, and the motion is disabled when the system asks for reduced motion.
- **Session groups use the same collapse motion.** Project rows stay mounted so the left rail does not jump when a group folds.
